# Autonomous E-Commerce Operations & Marketing Agent 🚀

An AI-powered multi-agent system built using **CrewAI** for automating customer review analysis, sentiment extraction, and operational insight generation for e-commerce stores.

## 🌟 Features
- **Customer Sentiment Analysis:** Evaluates product feedback automatically.
- **Structured Insights:** Generates actionable Pros and Cons summaries.
- **CrewAI Multi-Agent Workflow:** Scalable logic for autonomous operations.

## 🛠️ Tech Stack
- **Framework:** CrewAI
- **Language:** Python 3.12
- **Environment Management:** Virtual Environment (`venv`)
